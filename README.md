# Netflix Data Analysis with Python and SQL

This project analyzes the Netflix titles dataset using Python, Pandas and SQL-style analysis.

Dataset size: ~8800 titles.

## Technologies Used

- Python
- Pandas
- SQL concepts
- Data Analysis
- GitHub

## Analysis Performed

The project explores:

• Movies vs TV Shows distribution  
• Top countries producing Netflix content  
• Content trends by release year  
• Most common ratings on Netflix  

## Files

analysis.py → Python analysis script  
data/netflix_titles.csv → Dataset used for analysis

## Example Insights

- Netflix contains more Movies than TV Shows.
- The United States produces the largest amount of Netflix content.
- Content production increased rapidly after 2015.
